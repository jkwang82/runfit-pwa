# RUN & FIT PWA — 시작 안내

## 포함된 기능
- 식단별 칼로리·단백질 기록 및 하루 합계
- 러닝 거리·시간·페이스 기록
- 날짜별 체중 기록 및 목표 진행률
- 일일/주간 체크리스트
- 월간·주간 러닝 합계
- JSON 백업 및 복원
- PWA 오프라인 앱 셸 캐시

## 중요: 저장 방식
기록은 브라우저의 `localStorage`에 저장됩니다. 서버로 자동 전송하지 않습니다. 단, 브라우저 데이터 삭제, 앱 제거, 브라우저/기기 변경 시 기록이 사라질 수 있습니다. 정기적으로 `계획 > 데이터 백업 및 복원`에서 JSON 파일을 내려받아 보관하세요.

## Android에 설치하는 방법
PWA 설치에는 HTTPS로 제공되는 웹 주소가 필요합니다. 파일을 휴대폰에서 직접 여는 `file://` 방식은 설치 및 오프라인 기능이 제대로 작동하지 않습니다.

### 간단 배포: GitHub Pages
1. PC 또는 모바일 브라우저에서 GitHub 계정에 로그인합니다.
2. 새 저장소(repository)를 만들고 `runfit-pwa` 같은 이름을 지정합니다.
3. 이 ZIP의 파일을 압축 해제한 뒤 저장소 최상위(root)에 모두 업로드합니다.
4. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, branch를 `main`, folder를 `/(root)`로 설정하고 저장합니다.
5. 배포가 완료되면 `https://계정이름.github.io/저장소이름/` 형태의 주소를 엽니다.
6. Android Chrome에서 주소를 연 다음 메뉴 `⋮` → **홈 화면에 추가** 또는 **앱 설치**를 선택합니다. 메뉴 이름은 Chrome 버전에 따라 다를 수 있습니다.
7. 설치 후 앱을 열어 테스트 기록을 입력하고, 백업 파일을 내려받을 수 있는지 확인합니다.

## 데이터 백업/복원
- 백업: 계획 탭 → `백업 파일 내보내기`
- 복원: 계획 탭 → JSON 파일 선택
- 복원은 현재 기록을 교체하므로, 먼저 현재 데이터 백업을 권장합니다.

## 건강 관련 안내
칼로리 목표는 추정치이며 의료적 조언이 아닙니다. 장거리 훈련일에는 필요한 에너지와 탄수화물을 충분히 섭취하고, 지속적인 피로·어지럼증·훈련 성능 저하가 생기면 계획을 조정하세요.
